# Home theatre

Basement rack: Denon, Hypex, sources. Family room: TV, speakers, sub. Homeruns done.

| Channel | Speaker | Amp now | Amp later |
|---------|---------|---------|-----------|
| L / C / R | 3× CWM73 S2 | NCx500 ch 1/2/3 ← Denon pre-out | same |
| Surround L / R | 2× CWM663 | Denon internal | NCx252MP ch 1–2 |
| Atmos L / R | 2× CCM662 | Denon internal | NCx252MP ch 3–4 |
| Sub | HSU VTF-15H MK2 | Denon LFE → RCA homerun; sub on local AC | same |

Denon: Front L/R/C = Pre-out. HDMI sources → Denon (basement) → HDMI homerun → LG B7. Never source-to-TV.

```text
PS5 / Switch 2 / Apple TV --HDMI--> Denon
  pre-out L/C/R --> NCx500 --> CWM73 S2
  internal amps --> CWM663 + CCM662
  LFE --> HSU
  HDMI out --> LG B7
```

Power: Furman (socket A) for Denon, Hypex, sources. HSU and B7 on family-room circuits. See `rack/power.md`.

Power-on: Furman → NCx500 → Denon → sources. Off: reverse.

HSU: LFE mode on; Denon owns crossovers. Start phase 0°.

Starting crossovers (confirm after Audyssey at MLP): LCR/surround 80 Hz, Atmos 120 Hz.

B7: HDR10 path; ARC on the Denon input (this set has no eARC). Sources → Denon for Atmos.

CBS350: PS5 port 5, Apple TV 6, Switch 2 7.
